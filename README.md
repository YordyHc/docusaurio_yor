## 💻 Requisitos previos

Antes de comenzar, asegúrate de tener instalado:

- **Node.js:** versión 18 o superior.
- **npm:** gestor de paquetes de Node.js.
- **Git:** para clonar el repositorio.

---

## 🚀 Instalación y configuración

Sigue estos pasos para ejecutar el proyecto en tu entorno local.

### 1\. Clonar el repositorio

bash

```bash
git clone https://github.com/YordyHc/docusaurio_yor.git
```

### 2\. Acceder al directorio

bash

```bash
cd docusaurio_yor
```

### 3\. Instalar dependencias

bash

```bash
npm install
```

### 4\. Iniciar el servidor de desarrollo

bash

```bash
npm start
```

Una vez iniciado, abre tu navegador en:

text

```text
http://localhost:3000
```

---

## 📦 Construcción y despliegue

Para generar una versión optimizada para producción:

bash

```bash
npm run build
```

Para visualizar localmente la versión compilada:

bash

```bash
npm run serve
```

Los archivos generados se almacenarán en la carpeta `build/`.

---

## 🧰 Comandos disponibles

| Comando           | Función                               |
| ----------------- | ------------------------------------- |
| `npm start`       | Inicia el servidor de desarrollo      |
| `npm run build`   | Genera la versión de producción       |
| `npm run serve`   | Previsualiza el sitio compilado       |
| `npm run clear`   | Limpia la caché de Docusaurus         |
| `npm run swizzle` | Personaliza componentes de Docusaurus |
| `npm run deploy`  | Ejecuta el despliegue configurado     |

## 🤝 Contribuciones

¡Las contribuciones son bienvenidas\! Si deseas mejorar el contenido, corregir errores o agregar nuevas funcionalidades, puedes colaborar siguiendo estos pasos:

**1.** Haz un fork del repositorio.

**2.** Crea una rama para tus cambios:

bash

```bash
git checkout -b mejora/documentacion
```

**3.** Realiza tus modificaciones y verifica que el proyecto funcione correctamente:

bash

```bash
npm run build
```

**4.** Crea un commit descriptivo:

bash

```bash
git add .
git commit -m "docs: mejorar documentación"
```

**5.** Envía tus cambios y abre un Pull Request.

> 💡 Antes de contribuir, revisa la ortografía, el formato de las imágenes y el funcionamiento de los enlaces.
